# ssv-video — Генератор видео-пакетов для SSVproff

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

Автоматизированный инструмент для создания **готовых к публикации пакетов** для YouTube-канала **[@SSVproff-22.06](https://www.youtube.com/@SSVproff-22.06)**.

Генерирует:
- SEO-оптимизированное описание и заголовок  
- Превью в фирменном стиле SSVproff  
- Теги, главы, чек-лист публикации  
- README.md для синхронного GitHub-репозитория  
- Поддержку open-science workflow

Разработан профессором С.В. Сушковым для медицинского сообщества.
