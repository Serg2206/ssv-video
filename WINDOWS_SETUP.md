# 🪟 Установка SSVproff Video Creator на Windows

Пошаговая инструкция для запуска генерации видео **SSVproff** на компьютере с Windows
с помощью автономного установщика `bootstrap.py`.

> **Главное преимущество:** `bootstrap.py` сам создаёт изолированное окружение,
> устанавливает все зависимости и **обходит необходимость в ImageMagick**
> (весь текст рисуется через библиотеку Pillow). Вам не нужно ничего настраивать
> вручную — кроме самого Python.

---

## 1. Требования

| Требование | Детали |
|------------|--------|
| **ОС** | Windows 10 или 11 (64-bit) |
| **Python** | **3.8 или новее** (рекомендуется 3.10+) |
| **Интернет** | Нужен для скачивания зависимостей и (опционально) для озвучки gTTS |
| **Место на диске** | ~500 МБ (виртуальное окружение + ffmpeg) |

### Установка Python (если ещё не установлен)

1. Откройте https://www.python.org/downloads/windows/
2. Скачайте установщик **Python 3.10+** (Windows installer, 64-bit).
3. Запустите установщик и **обязательно поставьте галочку**
   ✅ **«Add Python to PATH»** на первом экране.
4. Нажмите *Install Now* и дождитесь окончания.
5. Проверьте установку — откройте **Командную строку** (`cmd`) и выполните:
   ```bat
   python --version
   ```
   Должно вывести `Python 3.10.x` (или вашу версию ≥ 3.8).

> ⚠️ Если команда `python` не распознаётся — переустановите Python с галочкой
> «Add Python to PATH» или используйте команду `py` вместо `python`.

## 2. Скачивание и запуск `bootstrap.py`

### Вариант A — скачать весь репозиторий (проще всего)

1. Откройте страницу репозитория на GitHub.
2. Нажмите зелёную кнопку **`Code`** → **`Download ZIP`**.
3. Распакуйте архив, например, в `C:\ssv-video`.
4. Откройте **Командную строку** и перейдите в эту папку:
   ```bat
   cd C:\ssv-video
   ```
5. Запустите установщик:
   ```bat
   python bootstrap.py
   ```

### Вариант B — скачать только `bootstrap.py`

1. На GitHub откройте файл `bootstrap.py`.
2. Нажмите кнопку **`Raw`**, затем `Ctrl + S` — сохраните файл,
   например, в `C:\ssv-video\bootstrap.py`.
3. В командной строке:
   ```bat
   cd C:\ssv-video
   python bootstrap.py
   ```

### Вариант C — через Git (для продвинутых)

```bat
git clone https://github.com/Serg2206/ssv-video.git
cd ssv-video
python bootstrap.py
```

> Если `python` не работает, попробуйте `py bootstrap.py`.

## 3. Что произойдёт при запуске

Скрипт выполнит шаги автоматически и будет печатать прогресс с префиксом `[bootstrap]`:

1. **Проверка Python** — убедится, что версия ≥ 3.8.
2. **Создание окружения** — создаст папку `.ssv_venv` (изолированный venv),
   чтобы не засорять системный Python.
3. **Установка зависимостей** — поставит:
   - `pillow` — отрисовка текста на кадрах (вместо ImageMagick);
   - `moviepy` — сборка и кодирование видео;
   - `imageio-ffmpeg` — **сам устанавливает ffmpeg** (отдельная установка не нужна);
   - `numpy` — работа с кадрами;
   - `gTTS` — озвучка текста (опционально, нужен интернет).
4. **Перезапуск внутри venv** — скрипт перезапустит сам себя интерпретатором из `.ssv_venv`.
5. **Генерация тестового видео** — нарисует несколько фирменных слайдов SSVproff
   (вертикальный формат 1080×1920 для YouTube Shorts), при наличии интернета добавит
   озвучку и закодирует ролик.

⏱️ Первый запуск занимает **3–10 минут** (зависит от скорости интернета и диска).

## 4. Как проверить результат

После успешного завершения вы увидите сообщение:

```
[bootstrap] ==================================================
[bootstrap] ГОТОВО! Тестовое видео создано:
[bootstrap]   C:\ssv-video\output\ssvproff_bootstrap_test.mp4
[bootstrap] Если файл открывается и воспроизводится — установка прошла успешно.
[bootstrap] ==================================================
```

1. Откройте папку `output` внутри проекта.
2. Найдите файл **`ssvproff_bootstrap_test.mp4`**.
3. Откройте его двойным щелчком (проигрыватель Windows / VLC).
4. Видео должно быть **вертикальным**, с фирменной полосой **SSVproff** сверху,
   крупным текстом по центру и плашкой-дисклеймером снизу.

✅ Если видео воспроизводится — окружение настроено корректно, и можно переходить
к полной генерации (см. основной `README.md`).

## 5. Troubleshooting (типичные ошибки Windows)

<details>
<summary><b>❌ «python не является внутренней или внешней командой»</b></summary>

Python не добавлен в PATH. Решения:
- Переустановите Python с галочкой **«Add Python to PATH»**, **или**
- Используйте команду `py` вместо `python`:
  ```bat
  py bootstrap.py
  ```
</details>

<details>
<summary><b>❌ Требуется Python 3.8+, а у вас 3.7 (или старее)</b></summary>

Установите свежий Python 3.10+ с https://www.python.org/downloads/ и
запустите скрипт заново.
</details>

<details>
<summary><b>❌ Ошибка установки зависимостей / «Could not find a version»</b></summary>

- Проверьте подключение к интернету.
- Если вы за корпоративным прокси — настройте переменные окружения
  `HTTP_PROXY` / `HTTPS_PROXY` перед запуском.
- Повторите запуск: `python bootstrap.py` (уже созданный venv будет переиспользован).
</details>

<details>
<summary><b>❌ «PermissionError» / «Отказано в доступе» при создании venv</b></summary>

- Не запускайте скрипт из системных папок (`C:\Program Files`, `C:\Windows`).
  Используйте, например, `C:\ssv-video` или папку в профиле пользователя.
- Закройте антивирус/блокировщик, если он мешает созданию файлов.
</details>

<details>
<summary><b>⚠️ «ModuleNotFoundError: No module named ...» при ручном запуске</b></summary>

Вы запустили скрипт системным Python, а не из venv. Просто запустите
`python bootstrap.py` заново — он сам перезапустится внутри `.ssv_venv`.
Для ручной работы активируйте окружение:
```bat
.ssv_venv\Scripts\activate
```
</details>

<details>
<summary><b>⚠️ Озвучка пропущена / «Озвучка пропущена (это не критично)»</b></summary>

`gTTS` требует интернет и доступ к серверам Google Translate.
Видео всё равно создаётся — просто без звука. Проверьте интернет/прокси,
если озвучка нужна.
</details>

<details>
<summary><b>❌ Антивирус блокирует ffmpeg.exe</b></summary>

`imageio-ffmpeg` скачивает `ffmpeg` в профиль пользователя. Если антивирус
помещает его в карантин — добавьте папку проекта и
`%USERPROFILE%\.imageio` в исключения и повторите запуск.
</details>

<details>
<summary><b>❌ Долгое «зависание» на этапе кодирования</b></summary>

Это нормально для вертикального видео 1080×1920 — кодирование кадров занимает
время. Дождитесь сообщения `ГОТОВО!`. На слабых машинах процесс может идти
несколько минут.
</details>
