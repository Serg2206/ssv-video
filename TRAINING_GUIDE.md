## 🚀 Быстрый старт

### Шаг 1: Подготовка транскрипции

Создайте файл с транскрипцией видео в формате `.txt`. 

**Пример минимальной транскрипции:**
```
Здравствуйте, коллеги!

Сегодня мы рассмотрим лапароскопическую холецистэктомию.
Эта операция является золотым стандартом лечения желчнокаменной болезни.

Ключевые этапы операции:
1. Установка троакаров
2. Мобилизация желчного пузыря
3. Клипирование пузырного протока и артерии
4. Удаление желчного пузыря

Спасибо за внимание!
```

### Шаг 2: Запуск генерации

```bash
python main.py --input_file "input/cholecystectomy.txt"
```

### Шаг 3: Получение результатов

В папке `output/` вы найдёте:
- 📄 `title.txt` - SEO-оптимизированный заголовок
- 📄 `description.txt` - подробное описание
- 📄 `tags.txt` - релевантные теги
- 📄 `chapters.txt` - временные метки
- 🖼️ `thumbnail.png` - превью в фирменном стиле
- 📋 `README.md` - документация для GitHub

## 🎯 Основные сценарии использования

### 🎬 Сценарий 1: Простая генерация пакета

**Задача:** Создать пакет для публикации на YouTube без автоматической загрузки.

**Настройка `config.yaml`:**
```yaml
youtube:
  enabled: false
  
language: "ru"

ai:
  model: "gpt-4o"
  temperature: 0.7

thumbnail:
  method: "api"  # или "local"
```

**Команда:**
```bash
python main.py --input_file "input/surgical_lecture.txt"
```

**Результат:** Полный пакет в `output/surgical_lecture_2025-11-06/`

---

### 🚀 Сценарий 2: Автоматическая публикация на YouTube

**Задача:** Сгенерировать пакет И опубликовать видео автоматически.

**Предварительные требования:**
1. Настроен YouTube Data API v3
2. Получен `client_secrets.json`
3. Указан путь к видеофайлу

**Настройка `config.yaml`:**
```yaml
youtube:
  enabled: true
  video_path: "videos/my_surgery.mp4"
  privacy: "unlisted"  # public, unlisted, private
  category_id: "27"  # Education
```

**Команда:**
```bash
python main.py --input_file "input/advanced_technique.txt"
```

**Результат:** Видео опубликовано на YouTube со всеми метаданными!

---

### 🎥 Сценарий 3: Генерация видео из пакета

**Задача:** Создать видеофайл с текстом на экране (экспериментально).

**Настройка `video_config.yaml`:**
```yaml
method: "text_on_screen"
resolution: "1920x1080"
fps: 30
duration_per_slide: 5  # секунд

style:
  background_color: "#1a1a2e"
  text_color: "#ffffff"
  font_family: "Arial"
  font_size: 48
```

**Команды:**
```bash
# Шаг 1: Создать пакет
python main.py --input_file "input/procedure.txt"

# Шаг 2: Сгенерировать видео
python video_creator_main.py --package_path "output/procedure_2025-11-06/" --output_filename "procedure_video.mp4"
```

**Результат:** Видеофайл `output/procedure_video.mp4`

## ✅ Best Practices

### 1. Оптимизация транскрипций для ИИ

✅ **ДЕЛАЙТЕ:**
- Используйте четкую структуру с заголовками
- Разбивайте текст на логические блоки
- Указывайте временные метки (опционально)
- Используйте профессиональную терминологию
- Добавляйте ключевые слова для SEO

❌ **НЕ ДЕЛАЙТЕ:**
- Не пишите сплошным текстом без разбивки
- Избегайте жаргона и сленга
- Не используйте слишком короткие транскрипции (<200 слов)
- Не забывайте про структуру

### 2. Настройка конфигурации

**Для медицинского контента:**
```yaml
ai:
  model: "gpt-4o"  # Лучшее качество
  temperature: 0.6  # Меньше креативности, больше точности
  max_tokens: 2000
  
language: "ru"

thumbnail:
  style: "professional"
  color_scheme: "medical"  # Синий/белый
```

**Для образовательного контента:**
```yaml
ai:
  model: "gpt-4o-mini"  # Баланс цена/качество  
  temperature: 0.8  # Больше креативности
  
thumbnail:
  style: "engaging"
  color_scheme: "vibrant"
```
