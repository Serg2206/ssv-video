## 🏗️ Текущая Архитектура SSV-Video v2.0

### Модульная Структура

```
ssv-video/
├── main.py                      # Основной скрипт генерации пакетов
├── video_creator_main.py        # Генератор видео (экспериментально)
├── config.yaml                  # Конфигурация системы
├── video_config.yaml            # Конфигурация видео
│
├── modules/                     # Основные модули
│   ├── ai_generator.py          # ИИ генерация контента
│   ├── thumbnail_generator.py   # Создание превью
│   ├── packager.py              # Упаковка результатов  
│   └── youtube_uploader.py      # Публикация на YouTube
│
├── video_modules/               # Видео модули
│   └── text_on_screen_generator.py
│
├── utils/                       # Утилиты
│   └── __init__.py
│
├── input/                       # Входные транскрипции
└── output/                      # Результаты генерации
```

### Ключевые Возможности

1. **AI-генерация** (через OpenAI GPT-4):
   - SEO-оптимизированные заголовки
   - Подробные описания
   - Релевантные теги
   - Временные метки (chapters)

2. **Визуальный контент**:
   - Превью в фирменном стиле
   - Поддержка API и локальной генерации

3. **Автоматизация**:
   - Публикация на YouTube
   - Экспорт в GitHub
   - Open-science workflow
